# SolidOS Panes

A W3C Solid Community Group draft report describing how SolidOS shows a Solid pod through panes: what a pane is, how one is chosen, how panes are registered, and how to write one. Written down from the running code and the SolidOS team's notes.

Read it: https://melvincarvalho.github.io/solidos-panes/

Corrections welcome as issues or pull requests. The document may move under the SolidOS organisation later; this repository will then redirect.
